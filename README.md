# Catch the Egg

A simple C++ OpenGL game where the player moves a basket to catch falling eggs.

## Overview

- Written in C++.
- Uses OpenGL for rendering.
- Uses GLFW/GLUT for window/input handling.
- Uses GLEW/GLAD or native OpenGL setup.

## Controls

- Left arrow: move basket left.
- Right arrow: move basket right.
- Esc: quit the game.

## Gameplay

- Eggs fall from the top of the screen.
- The player moves a basket along the bottom.
- Catch eggs to score points.
- Missing an egg may end the game or cost a life.

## Build

1. Install a C++ compiler and OpenGL development libraries.
2. Install GLFW/GLUT and GLEW/GLAD.
3. Build the project with your preferred build system.
4. Run the generated executable.

## Notes

This project is best run with an OpenGL-compatible GPU and proper library setup.
